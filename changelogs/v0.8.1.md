## 🔧 Fixes

- **`ai_budget_seconds=0` plus `ai_timeout=0` really means no ceiling at all**: with both set to zero the AI stage has no deadline — the same "protection off" semantics the README documents. The v0.8.0 note saying both ceilings are still there and the worst case stays bounded only describes the normal setup (a non-zero total budget or a non-zero per-request timeout). To keep any protection, leave either one non-zero; the spirit's line keeps its own 20-second stage cap either way.
- **Oversized topic caches from older versions shrink on the next cache hit**: the 20-entry cap arrived in v0.8.0, so caches written before it may hold far more; previously trimming only ran after a new interpretation was written, so users who only revisited old topics kept the oversized dictionary. A cache hit now trims to 20 and persists it — the write happens outside the cache lock with a 2-second bound, so a stalled KV store cannot strand the hit — while the reading the user is waiting for is still returned.
