## ✨ 新功能

- **78 张牌义分层升级**：全部 78 张牌的释义不再只是一串关键词——正位拆为「关键词 + 事件走向 + 心法建议」，逆位拆为「关键词 + 能量状态 + 能量卡点 + 转身建议」（能量状态分过度 / 受阻 / 内化 / 松动四类，逆位不再被一律读成坏）；AI 解读素材更丰富，AI 不可用时本地牌义也更有引导性
- **内置字体子集扩展**：内置 Noto Sans SC 子集（Regular / Bold 同步，含静态字形清单）重新覆盖全部渲染文案——新增牌义之外，标题、牌名行、署名与水印里的空格、品牌字样一并纳入，牌面不再出现方块；跨平台渲染不依赖系统字体


## 🔧 修复

- **同一签的人格不再变脸**：`ai.persona` 设为随机时，「牌灵的话」与解读正文会各自随机——一句话一种腔调、正文换个人；现在一次占卜只抽一次人设，两者始终同一人格
- **冷却数据异常不再误伤占卜**：会话冷却里若存了异常数据，命令占卜会直接落进「这场占卜断了」；现在按「没有记录」放行，与每日次数限制的口径一致
- **牌灵的话不再因空回复中断**：模型只回了引号或纯空白时会把整次占卜带走，现在按「这次没生成」处理并回退池内签文
- **「情感」类问法不再被当成纯时间线问题**：选阵的关系语义词表曾抄了一份，漏掉「情感」——在「情感过去未来」这类含多个时间线词、又没有他/她/我们的问法里，会掉进纯时间线阵而不是关系阵；现在词表直接引用关键词表的情感组，不会再各自漂移
- **解读缓存被写坏不再永久失效**：每日牌运的解读缓存里若存了异常数据，写回会中断、坏值一直留着，之后每次问都重新生成，当天同一段解读的承诺也就破了；现在按「从空起步」处理，坏值当场被合法结构覆盖，解读恢复正常
- **同一天不同主题的解读不再串用**：同一天先问「今天运势」再问「今天财运」，原本会拿到同一段解读（谁先问谁定调），另一个主题等于答非所问；现在各主题各生成一段，而**当天的牌仍是同一张**——问的是同一天，牌该是同一张，该分开的是解读
- **纯文字模式的逐张牌义不再只剩最后一张**：AI 不可用时的本地牌义兜底（`text_only` 模式，或牌面图渲染失败且解读没生成时才会露出）此前只输出牌阵的最后一张——三张阵只看得到一张，其余牌义静默消失；现在每张牌各出一段

## ✨ New features

- **Layered readings for all 78 cards**: every card now carries more than keyword strings — uprights are split into keywords + what's unfolding + how to act, reversals into keywords + energy state + where the energy jams + how to turn around (the energy state is one of four — excess / blocked / internalised / loosening — so a reversal is no longer read as simply bad); the AI gets richer material and the built-in fallback reads more like guidance
- **Bundled font subset extended**: the built-in Noto Sans SC subset (Regular & Bold, static charset manifest updated) now covers every rendered string — the new meaning texts plus the spaces and brand characters used in titles, card labels, the signature and the watermark, so cards no longer show tofu boxes; rendering stays consistent across platforms without system fonts


## 🔧 Fixes

- **No more persona whiplash within one draw**: with `ai.persona` set to random, the spirit's line and the reading body were randomised separately — one line in one voice, the reading in another; a reading now draws its persona once so both always match
- **Corrupt cooldown data no longer derails a reading**: unexpected data in the session cooldown key dropped the command entry straight into the "this reading broke off" message; it is now treated as "no record" and passes, matching the daily cap's stance
- **The spirit's line no longer aborts a reading**: a reply containing only quotes or whitespace used to take the whole reading down; it now counts as "not generated" and falls back to the pool line
- **Relationship questions no longer mistaken for pure timeline readings**: the relation-word list was a hand-copied duplicate of the keyword table's emotion group and had missed one entry, so asks that combine several timeline words with an emotion word but name no explicit subject fell into the timeline spread instead of the relationship one; the list now derives from the keyword table, so the two can't drift apart
- **Corrupt cached data no longer breaks a reading for good**: if the daily reading cache held unexpected data, the write-back aborted and the bad value stayed — every later request regenerated and the "same reading all day" promise broke; it now starts from a clean slate and overwrites the bad value, so the cache recovers
- **Different topics on the same day no longer share one reading**: asking about general fortune and then about money on the same day returned the very same reading — whichever you asked first set the tone, so the second question effectively went unanswered; each topic now gets its own reading while the card stays the same one for that day (same day, same card, separate readings)
- **Card-by-card meanings are no longer cut down to the last card in text mode**: the built-in fallback meanings (shown in `text_only` mode, or when card rendering fails and no AI reading is available) used to print only the spread's last card — a three-card spread showed a single card and the rest vanished silently; every card now gets its own block
