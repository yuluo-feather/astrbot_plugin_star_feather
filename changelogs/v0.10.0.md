- **牌灵的话开关（`ai.spirit_line`）**：默认开启；关闭后每次占卜不再生成、不发送开头那句牌灵的话（连池内签文也不取），省一次 AI 调用与一条前置行（`/今日牌运` 海报上的签文与署名也一并隐藏），深度解读不受影响

## 🔧 修复

- **会话冷却不再提前放行**：剩余时间向下取整会把 0.8 秒截成 0，记录的时间戳又截成整秒，两处叠加让实际冷却最多比配置短将近 2 秒；现在剩余时间向上取整、时间戳保留小数，冷却没真正走完就至少再等 1 秒
- **免责声明改为独立一条消息**：三种发送方式下，免责声明都在结果之后单独发送（合并转发时是卡片里的最后一个独立节点）；AI 不可用回退本地牌义时也遵循 `output.send_mode`，不再固定为图片 + 文本；免责声明留空则整条不发送
- **自然语言入口补齐异常出口**：意图解析、节流与每日计数等前置步骤抛出的异常不再漏给 Agent Loop，改为回一条「牌灵需要缓缓」；帮助页发送异常不再误用占卜失败文案，失败提示自己发不出去时也不会再抛第二次异常

## ✨ New

- **Spirit-line toggle (`ai.spirit_line`)**: on by default; when off, readings no longer generate or send the opening spirit line (not even the pool fallback) (the sign-off on the `/今日牌运` poster is hidden too) — one less AI call and one less lead-in message, with the deep reading unchanged

## 🔧 Fixes

- **Session cooldowns no longer release early**: remaining time was floored (0.8 s became 0) and the stored timestamp was truncated to whole seconds, so the effective cooldown could run up to nearly 2 s shorter than configured; remaining time now rounds up and the timestamp keeps sub-second precision, so a cooldown that is not truly over always reports at least 1 more second
- **The disclaimer is now its own message**: in all three send modes it follows the reading as a separate message (inside a merged forward it is the last node); AI-less fallbacks also follow `output.send_mode` instead of always sending an image + text chain. An empty disclaimer sends nothing
- **The natural-language entry now has one exception exit**: failures in intent parsing, throttling or the daily counter no longer escape to the Agent Loop and instead send the usual "the cards need a moment" note; a failed help send no longer uses the divination-failure copy, and a failure notice that cannot be sent no longer raises a second exception
